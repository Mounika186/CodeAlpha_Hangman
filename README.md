# CodeAlpha_Hangman

## Python Hangman Game

This is a simple text-based Hangman game developed using Python as part of my CodeAlpha Python Programming Internship.

## Features
- Random word selection.
- Displays hidden letters using underscores.
- Allows the player to guess one letter at a time.
- Maximum of six incorrect attempts.
- Displays Hangman drawings for wrong guesses.
- Validates user input.
- Prevents repeated guesses.
- Displays win or lose messages.

## Technologies Used
- Python
- Random module
- Lists
- Strings
- While loops
- Conditional statements

## How to Run
1. Install Python.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run:

```bash
python hangman.py
```
